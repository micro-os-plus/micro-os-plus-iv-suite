# scripts

This folder holds the scripts used to maintain this repository.

- `update-submodules.mjs` - update all submodules to the latest commit of their
  `xpack` branch; use `--help` for details, or run it via the
  `update-submodules` and `update-submodules-check` npm scripts

The scripts are written in JavaScript (Node.js), to be portable on all
platforms.
